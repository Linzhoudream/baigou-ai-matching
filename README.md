# 白沟AI匹配台

> 箱包产业AI智能供需撮合平台

## 项目简介

白沟AI匹配台是一个专为白沟箱包产业集群打造的AI智能供需撮合平台。帮助采购商快速筛选优质加工厂，帮助加工户零门槛发布高质量信息，实现产业上下游的高效对接。

## 核心功能

- **AI智能匹配**：输入大白话需求，AI自动解析角色、品类、数量、交期等关键信息，智能匹配互补的供需双方
- **零门槛发布**：AI向导式发布流程，选择角色→选择品类→补充信息→预览发布，4步搞定
- **AI产业顾问**：每条帖子自动生成产业分析（卡点/建议/风险），帮助用户规避交易风险
- **多角色覆盖**：加工厂、采购商、辅料供应商、电商卖家、物流等全产业链角色

## 技术栈

- 纯前端实现（HTML + CSS + JavaScript）
- 规则引擎驱动的智能匹配
- 响应式设计，支持PC和移动端

## 快速开始

直接在浏览器中打开 `index.html` 即可运行。

## 项目结构

```
├── index.html    # 主页面
├── styles.css    # 样式文件
├── app.js        # UI交互逻辑
└── rules.js      # 核心规则引擎
```
